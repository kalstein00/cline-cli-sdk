# 연결과 원격 작업의 수명 분리

2026-10-09 설계 인터뷰에서 GUI 종료나 SSH 단절만으로 원격 작업을 종료하지 않기로 결정했다. 다시 연결하면 작업의 진행 상황과 대기 중인 질문을 복구해야 한다. 사용자가 명시적으로 중단한 경우와 연결이 사라진 경우를 구분한다.

첫 버전은 예제 앱 하나에서 한 번에 원격 작업 하나를 조작한다. 저장된 여러 세션 중 하나를 선택하는 기능과 여러 실행을 동시에 조작하는 기능을 구분하며, 여러 앱의 동시 조작은 첫 버전 범위에 포함하지 않는다.

첫 버전은 SDK로 시작한 작업의 기록 조회, 재연결, 재개를 우선 지원한다. 별도 터미널에서 시작한 임의의 Cline 실행을 인계받는 기능은 제외한다. 기존 Cline 기록을 가져오는 기능은 저장 형식과 재개 방법을 확인한 뒤 확장한다.

작업 중단은 현재 수행 중인 원격 작업을 멈추고 대화 기록을 보존하는 동작이다. 연결 해제는 원격 작업을 계속 실행시키는 동작으로 구분한다. 중단 후 같은 대화를 이어갈 수 있는지는 실제 CLI에서 확인하고 검증된 범위만 제공한다.

회사 CLI 코드를 수정하지 않는 범위에서, 사용자 계정 권한으로 실행하는 작은 원격 실행 관리 프로그램을 설계 후보에 포함한다. 기존 환경만으로 작업 유지와 재접속이 가능한지 먼저 관찰하고 부족할 때 보조 프로그램을 검토한다. 특정 프로그램의 설치나 실행 방식은 아직 정하지 않았다.

구체적인 원격 실행 유지 방식, CLI에 작업 중단을 전달하는 방법, 재접속 시 응답 전송을 확인하는 방법은 실제 CLI 관찰 후 결정한다. 이 ADR은 요구사항을 기록하며, 해당 기능의 구현 가능성이나 복구 성공을 보증하지 않는다.
