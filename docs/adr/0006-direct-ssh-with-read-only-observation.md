# 원격 helper 없이 설치된 CLI를 직접 실행한다

회사 서버에 SDK Python 코드를 전송·실행하지 않는다는 요구에 따라, SSH로 설치된 Cline CLI를 tmux의 개별 argv 실행으로 시작하고 파일 및 tmux 조회 결과를 로컬에서 해석한다. ADR-0002의 연결과 작업 수명 분리는 유지하되 supervisor 선택을 폐기하며, ADR-0005의 native 인증·설정 사용을 기본으로 한다. 원격 SDK 실행 파일과 입력 ledger는 만들지 않는다.

tmux 화면 조회와 키 입력 사이의 상태 변경, 중복 전송 방지, 자식 프로세스 소유권을 보장할 수 없으므로 ADR-0003에 따라 후속 입력·승인/질문 응답·재개·중단을 비활성화한다. 저장된 JSON 대화는 사용자가 명시적으로 선택하는 읽기 전용 기록이며, 수정 시각이나 프롬프트 일치로 현재 실행과 결합하지 않는다. 자동 승인은 켜지 않으며 상호작용은 사용자가 원격 CLI에서 직접 수행한다. 향후 설치된 CLI가 검증 가능한 공식 상호작용 프로토콜을 제공할 때 기능을 다시 검토한다.
