# Node.js SDK와 로컬 웹 예제 앱

2026-10-09 설계 인터뷰에서 첫 SDK를 Node.js와 Electron에서 사용하는 독립 TypeScript 패키지로 결정했다. SDK는 소비 앱의 UI 프레임워크나 DART의 제품 상태에 의존하지 않고, 원격 Cline 연동을 담당한다. 비 Node 소비 앱을 위한 범용 프로세스 인터페이스는 첫 버전에 포함하지 않는다.

예제 앱은 로컬 Node 서버에서 SDK를 사용하고 브라우저에 자체 GUI를 제공한다. 사용자는 별도 데스크톱 실행 파일 없이 예제를 실행한다. 향후 Electron 소비 앱은 같은 SDK를 재사용한다.

첫 검증 범위는 Windows에서 예제 앱을 실행하고 Linux 서버의 Cline에 SSH로 연결하는 조합이다. 다른 OS 조합으로 확장할 수 있는 구조를 유지하되, 검증 전에 지원을 약속하지 않는다.

첫 SSH 인증 범위는 키 파일과 SSH agent다. 회사 환경에 비밀번호, MFA, 점프 서버 등 필수 접속 조건이 확인되면 초기 범위를 재검토한다. 이 결정은 회사 환경에서 해당 인증 방식으로 접속할 수 있음을 확인한 것이 아니다.

첫 작업 입력은 원격 작업 디렉터리와 텍스트 요청이다. DART의 선택 로그 같은 제품별 컨텍스트는 소비 앱이 텍스트로 구성해 전달한다. 파일 업로드, 첨부 관리, 스킬 설치와 업데이트는 후속 범위로 두고 질문·응답·복구와 진단을 먼저 완성한다.

Native GUI도 검토했으나, SDK 검증을 위해 별도 런타임 연동과 배포 경계를 추가할 필요가 없도록 로컬 웹 예제를 선택했다. 이는 SDK와 예제 앱의 구조에 관한 결정이며, 회사 Cline과의 호환성이나 실제 동작을 검증했다는 뜻은 아니다.
