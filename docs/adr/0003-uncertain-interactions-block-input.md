# 불확실한 응답 전달과 질문 해석 시 조작 차단

2026-10-09 설계 인터뷰에서 사용자 응답의 전달 확인 전에 연결이 끊기면 재접속 후 상태 확인 없이 해당 응답을 자동 재전송하지 않기로 결정했다. 이미 승인되어 작업이 진행 중일 수 있으므로, 확인할 수 없는 경우에는 전달 여부 불명을 표시한다. 전송 성공 여부를 추정해 중복 조작하는 편의성보다 원격 실행의 정확성을 우선한다.

질문이나 응답 대상을 해석하지 못하면 지원하지 않는 상호작용으로 표시하고 응답 조작을 차단한다. 원격 작업이 완료되었다고 처리하지 않으며, 첫 예제 앱에는 일반 터미널 입력창을 포함하지 않는다. 상태와 진단 정보를 제공하고 필요하면 사용자가 별도 SSH 터미널에서 확인한다. SDK가 상태를 다시 확인하기 전에는 조작을 재개하지 않는다.

전달 여부와 조작 재개 가능성을 판정할 구체적인 관측 근거는 실제 CLI 조사 후 결정한다.
