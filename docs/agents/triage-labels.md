# Triage Labels

| Canonical role | Tracker label | 의미 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 관리자의 검토 필요 |
| `needs-info` | `needs-info` | 추가 정보 대기 |
| `ready-for-agent` | `ready-for-agent` | 스펙이 확정되어 에이전트 구현 가능 |
| `ready-for-human` | `ready-for-human` | 사람의 구현 필요 |
| `wontfix` | `wontfix` | 진행하지 않음 |

스킬이 triage 역할을 언급하면 이 표의 tracker label을 적용한다.
