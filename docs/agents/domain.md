# Domain Docs

## Before exploring

이 저장소는 단일 컨텍스트 구조를 사용한다.

- 루트 `GLOSSARY.md`를 읽는다.
- `docs/adr/`에서 작업 영역과 관련된 ADR을 읽는다.
- 향후 루트 `GLOSSARY-MAP.md`가 생기면 관련 컨텍스트의 용어집을 찾아 읽는다.

문서가 없으면 조용히 진행한다.
용어와 결정이 실제로 확정될 때 `domain-modeling` 스킬로 문서를 생성한다.

## Vocabulary and decisions

이슈 제목, 설계 제안, 가설, 테스트 이름에는 용어집에 정의된 용어를 사용한다.
필요한 용어가 없으면 기존 프로젝트 용어를 확인하고 실제 공백을 기록한다.
기존 ADR과 충돌하는 제안은 해당 ADR과 재검토 이유를 명시한다.
