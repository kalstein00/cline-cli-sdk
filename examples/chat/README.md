# Cline Chat 소비 앱

Node 서버가 설치된 `@cline-cli-sdk/sdk`의 공개 API를 호출하고 브라우저는 메시지를 표시합니다. 이 예제에 SSH 명령이나 CLI 파서는 없습니다.

저장소 루트에서 `npm ci` 후 `npm run example:chat`을 실행하고 http://127.0.0.1:4174 를 엽니다. Node.js 22 이상과 SSH로 접속할 Linux의 Python·tmux·검증된 Cline 프로필이 필요합니다. `CLINE_CHAT_PORT`로 포트를 변경합니다. 기존 `example:web`은 SDK 진단 화면입니다.

SSH 별칭, 고정 CLI 실행 경로, 관리 디렉터리, 작업 디렉터리와 격리 CLI 데이터 디렉터리를 설정합니다. 인증은 원격에서 준비합니다. 첫 메시지는 새 TUI 작업을 시작합니다. 첫 요청 뒤 살아 있는 같은 대화에 후속 메시지를 전송합니다. 입력 준비 상태가 확인된 때만 버튼이 활성화됩니다. 후속 메시지는 원문 그대로 printable 한 줄 UTF-8 112바이트 이내이며, 앞뒤 공백·제어 문자·slash command·@ mention은 지원하지 않습니다. 현재 질문은 선택 버튼이나, SDK가 자유 응답을 허용할 때 질문 응답 입력창으로 처리합니다. 질문 자유 응답은 UTF-8 1,024바이트 이내의 printable 한 줄입니다. 도구 승인은 도구명과 전체 인자를 확인하고 승인 또는 거절을 직접 선택합니다. 일반 메시지와 질문 응답은 서로 다른 공개 API를 사용합니다. 전달 확인은 새 user 메시지 ID를 근거로 하며 답변 완료와 다릅니다. 전달 불명은 초안을 유지하고 새 입력을 차단합니다.

다른 프로젝트에서는 SDK를 build·pack한 `.tgz`를 설치한 뒤 이 예제의 패키지와 정적 파일을 가져갑니다. 예제의 SDK 의존성을 설치한 `.tgz`로 지정하고 `npm start`로 실행합니다. SDK 내부 소스나 저장소의 테스트 자료는 필요하지 않습니다. SDK 패키지에는 원격 helper도 포함됩니다.

`CLINE_CHAT_DIAGNOSTICS`를 지정하면 SDK의 제한된 원시 진단을 해당 디렉터리에 수집합니다. 진단에는 대화·도구 입력·터미널 내용이 포함될 수 있으므로 공유 전 검토해야 합니다. 기본은 비활성입니다.

연결 설정만 브라우저에 저장합니다. 키 파일 경로·키 내용·대화·초안·원격 출력은 기본 영구 저장하지 않습니다. 화면/서버 종료로 원격 작업이 중단되는 것은 아닙니다. 공개 CLI 수용과 회사 fork 호환성은 별도이며 회사 지원은 미검증입니다.
